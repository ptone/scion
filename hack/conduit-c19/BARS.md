# Criterion 19 Pass Bars — Audit Specification

This table is the normative contract for every pass bar evaluated by
`hack/conduit-c19` (`c19driver.BuildReport`). No bar may report `PASS` when its
underlying requirement was not measured or when degraded inputs would mask a
failure, and no bar is mapped to a package clause it does not fully measure:
unmeasured sub-clauses are split into separately named unevaluated bars.

Every bar maps directly to the Phase 8 live verification clauses (`L6a`, `L6b`,
`L6c`) from v2.17 and v2.22 §6.2.

## Verdict Semantics

- **PASS**: every bar emitted for the mode is `evaluated == true && pass == true`,
  or `evaluated == false && waived == true` (explicitly listed in
  `--allow-unevaluated`, echoed in the JSON report).
- **FAIL**: one or more evaluated bars have `pass == false`. Exit code `1`.
  `FAIL` is **never** waivable.
- **INCOMPLETE**: no evaluated bar failed, but one or more required bars have
  `evaluated == false` and are not listed in `--allow-unevaluated`. Exit code
  `1`. Unevaluated bars always carry `pass: false`.

## Claim Boundaries (Non-Negotiable Disclosures)

- **`control_p99_added`**: measures PTY open + echo + close on `agent[0]`'s Conduit session, not a hub→agent control RPC.
- **`deliver_paste_p99`**: measures fake-agent `RecordingTmuxRunner` handler time (`ExtraSubmits=2, 300ms`), not real `tmux` subprocess I/O. Large payloads are 33 × 15,000-byte `run_tag`-tagged rows coalesced by the broker with Hub `RenderDeliveryText` envelopes (≈507–520 KiB total; `messaging.offload_threshold_runes` must be disabled).
- **`broker_flush_mode`**: `c19BrokerFlusher` mirrors `pkg/agent/msgbuffer.go` v2.22 flush/sub-flush/retry logic with a configurable debounce (`--broker-debounce`, default `500ms` vs production `2s`), echoed in the JSON report.
- **`rotate_token_mix`**: Hub has no HTTP route invoking `Server.RequestAgentTokenRotation`; remains `INCOMPLETE` unless explicitly waived via `--allow-unevaluated=rotate_token_mix`.
- **`planned_drain_refuses_new_streams`**: split from `planned_drain_4503` and always `INCOMPLETE` unless waived; verify directly in L2/L3.
- **Single-host Lane 2a**: `clock_skew` is static (`--clock-skew`); relay-hop share depends on `--agents-file` `hub_url` split and LB placement.
